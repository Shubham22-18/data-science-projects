# Password Generator

A Python-based Password Generator that creates strong and random passwords using letters, numbers, and special characters.

## Features

- Generate secure random passwords
- User-defined password length
- Includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Menu-driven interface

## Technologies Used

- Python
- Random Module
- String Module

## Concepts Used

- Functions
- Loops
- Conditional Statements
- User Input Handling
- Random Number Generation

## How to Run

1. Save the file as:

   password_generator.py

2. Open Terminal or Command Prompt.

3. Run:

   python password_generator.py
