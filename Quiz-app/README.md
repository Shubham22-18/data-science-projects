# Quiz App

A simple Python Quiz Application that tests users with multiple-choice questions and calculates their final score.

## Features

- Multiple-choice questions
- Automatic score calculation
- Instant feedback for answers
- Percentage calculation
- Command-line interface

## Technologies Used

- Python

## Concepts Used

- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input Handling

## Project Structure

quiz-app/

## How to Run

1. Save the file as:

   quiz_app.py

2. Open Terminal or Command Prompt.

3. Run:

   python quiz_app.py
